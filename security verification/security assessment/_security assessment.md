> **Security assessment** nowadays there is an unprecedented explosion of cyber-attacks due to many reasons. The point is that also hackers are spending a huge amount of effort (instead of the past when it was more like a hobby). This leads to the **defender’s dilemma**: attacking a system is much easier than defending a system. This is because to attack a system it is enough to find one way to attack the system, while to defend the system we must find all possible ways of attacking it and apply measures against all attacks. The lack of one of these measures lead to a vulnerable system.


[[security verification/security assessment/security key concepts|security key concepts]] -> [[security verification/security assessment/vulnerability|vulnerability]] -> [[security verification/security assessment/vulnerability life cycle|vulnerability life cycle]]



In order to perform a **security assessment** of a system it is necessary to look for its vulnerabilities and their related exploits like the task of an attacker, but may use more information than available to an attacker.

A mix of different techniques can be used:
- [[security verification/security assessment/intro - Vulnerability Assessment|intro - Vulnerability Assessment]], [[security verification/security assessment/dynamic/intro - penetration testing|intro - penetration testing]]
- [[security verification/security assessment/intro - Analysis|Code Analysis]], [[security verification/security assessment/static/intro - formal verification|intro - formal verification]], [[security verification/security assessment/intro - Security Auditing (reviews)|Auditing]]


A security assessment can be have different objectives:
- A software vendor wants to assess the security of the developed software product (Assessment during development)
- A system administrator wants to assess the security of the administered system (Assessment during development)
- A software vendor or administrator wants to assess the security of a software product developed by a third party (Assessment done by user)
- A software vendor or system administrator wants to provide a security certification of the developed software product or administered system (Certification)
