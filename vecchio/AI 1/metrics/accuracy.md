Accuracy is a metric used for model evaluation and is generally defined as:
$$\text{Accuracy} = \frac{\text{Number of correctly classified objects}}{ \text{Number of classified objects}}$$

Note that accuracy can be misleading because a classifier that fails to detect all the objects from a specific class might still get high accuracy if the number of objects belonging to that class is few.

In other words, **accuracy does not provide any information about how well a classifier identifies the objects of one specific class**.
