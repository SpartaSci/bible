Def. (Algorithm) 
A finite set of instructions that when executed on a given input is guaranteed to return an output.
- **Deterministic** (no random stuff) same input, always the same output
- Always terminate (no infinite loop, no pauses)
- has an infinite amount of writable/readable memory.


To give a precise mathematical definition of algorithm one needs to introduce **Turing machines**, when are an idealized model of computer.


**Church-Turing thesis** 
Everything that can be compute, can be computed by a Turing machines.
