

**RFC-3279** specifies the cryptographic algorithms that MUST be supported by applications using the **RFC-3280** profile. It includes several older algorithms for backward compatibility, as well as newer ones. The algorithms are categorized as follows:

- **Digest Algorithms**:
  - MD-2
  - MD-5
  - **SHA-1** (preferred)

- **Signing Algorithms for Certificates / CRLs**:
  - RSA
  - DSA
  - **ECDSA** (Elliptic Curve DSA)

- **Subject Public Key Algorithms (SubjectPublicKeyInfo)**:
  - RSA
  - DSA
  - KEA
  - **DH** (Diffie-Hellman)
  - **ECDSA**
  - **ECDH** (Elliptic Curve Diffie-Hellman)

The underlined algorithms were added in **RFC-3279** compared to **RFC-2459**.

### Additional Specifications and Algorithm Extensions

Several updates and RFCs have extended the algorithms defined in RFC-3279:

- **RFC-4055**: Introduces improved specifications for signatures, including the Probabilistic Signature Scheme (PSS), the Optimal Asymmetric Encryption Padding (OAEP), and SHA-2 functions for computing digests.
  
- **RFC-4491**: Provides specifications for using the **GOST** algorithm family, which is used predominantly in Russia.

- **RFC-5480**: Expands support for **Elliptic Curve (EC)** keys of all types.

- **RFC-5758**: Adds support for new algorithms in the **SHA-2** family, including **SHA-224** and **SHA-256**.

- **RFC-8692**: Introduces the use of **SHAKE128** and **SHAKE256**, which are part of the **SHA-3** family of algorithms.
