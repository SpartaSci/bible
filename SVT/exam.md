# Certification Standard

**In the context of the Common Criteria, what are Evaluation Assurance Levels? In what cases an EAL level is higher than another one?**

The Common Criteria is a framework for evaluating the security of Information Technology products. One of the key concepts in the CC is the Evaluation Assurance Level, which is a numeric rating that reflects the depth and rigor of the security evaluation performed on a particular IT product.

There are seven EAL levels, ranging from EAL1 (the lowest level) to EAL7 (the highest level). Each EAL level represents a progressively more stringent set of requirements for the security evaluation process. In general, an EAL level is higher than another one when there are more security components and the testing involves more formal procedures

**What are security evaluation standards? What are the Common Criteria?**
Security evaluation standards are frameworks (or guidelines) which are used to measure the se- curity level of a given system (it may be a company, a network, etc.). Common Criteria is an internationally recognized IT security evaluation standard, which provides a framework for evaluating the security of IT products.

**CCRA**
CCRA (Common Criteria Recognition Arrangement) is an international agreement between Authorizing Nations (the ones that produce certificates, which have developed their own Evaluation Scheme to accredit laboratories to perform CC evaluations) and Consuming Nations (which don’t have their own Evaluation Scheme but want to recognize CC evaluations done by others). All nations signers of the CCRA recognize the results of evaluations done by the Authorizing Nations.






**Explain the CC goals.**
- Provide a common standard reference for evaluating/certifying IT system security.
- Permit the comparability between the results of independent security evaluation.
This is achieved by providing a standard/uniform approach to evaluation/certification, way of expressing security requirements and assurance levels, set of constraints on the evaluation methodology.

**What is security assurance in the context of security assessment and certification standards? Give a precise definition. What is the main technique that can be used to achieve security assurance? Make at least three concrete examples of such techniques (or different types).**

It is the measurable confidence that an entity meets its security requirements. Security assurance can be achieved by employing different assurance techniques: a security mechanism, a development methodology, security assessment techniques. . . Also, there exist different classes of security assurance techniques: formal, semi-formal, informal. Moreover, they can apply to different development stages: policy assurance, design assurance, implementation assurance, operational assurance.
