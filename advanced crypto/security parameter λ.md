
>Def. (security parameter)
A scheme has a **security parameter** (bit-level security) λ if in order to break the scheme an adversary requires (on average) $2^λ$ operations

Usually **λ** is 128,192,256


# cryptographic assumption

Assumption about the difficulty of solving some mathematical problems mostly from number theory and algebra.

Existence of **one way functions** or **collision-resistant functions** 

(relation with the P vs NP problem)
