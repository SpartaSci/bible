> this tool allows for the **acquisition** of **cloud storage objects**, such as S3 buckets or objects. It works by leveraging cloud provider APIs to securely access and download the required data to a local folder. The downloaded data can then be imported into FTK Imager for further analysis and processing.


A standalone, lightweight tool primarily used for **creating forensic images (bit-for-bit copies) of storage devices**, viewing forensic images, and extracting specific files or metadata without altering the original data.
